# Регламент разработки и ввода в эксплуатацию ПО

Проект: **Система управления продажами пищевых продуктов** (Food Sales Management System)  
Дисциплина: **Программная инженерия**

---

## Как просмотреть и редактировать документ

1. Основной документ регламента со всеми 9 обязательными разделами находится в файле [`index.html`](./index.html).
2. Чтобы открыть его в красивом виде: просто откройте `index.html` в любом браузере (Chrome, Edge, Firefox).
3. Документ содержит желтые маркеры `<span class="placeholder">...</span>` (ФИО студентов, номер группы) — их можно отредактировать в обычном блокноте, VS Code или любом текстовом редакторе.

---

## Публикация через GitHub Pages (по желанию)
Чтобы регламент открывался как полноценный сайт по ссылке:
1. Зайдите в репозиторий на GitHub: **Settings** -> **Pages**.
2. В разделе **Build and deployment** выберите источник: **Deploy from a branch**.
3. Ветка: `main`, папка: `/ (root)`. Нажмите **Save**.
4. Через 1 минуту ваш регламент будет доступен в интернете по ссылке вида `https://<username>.github.io/<repo>/`.
